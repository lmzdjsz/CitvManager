# B7 城市管理数字化平台 (CMPD)

期末上机项目 · 城市管理数字化平台设计与实现

## 环境要求

- Python 3.9+
- MySQL 8.x（需先启动，root 密码默认 `123456`）
- 依赖：`flask`、`flask-cors`、`pymysql`

安装依赖：
```bash
pip install flask flask-cors pymysql
```

## 启动步骤

```bash
# 1. 初始化数据库（建表 + 示例数据，只需执行一次）
python init_db.py

# 2. 启动后端
python app.py

# 3. 浏览器访问
#    http://127.0.0.1:5000/
```

如 MySQL 密码不同，修改 `config.py` 中的 `MYSQL.password`。

## 项目结构

```
config.py      MySQL 与 Flask 配置
db.py          数据库连接工具层
init_db.py     建表 + 示例数据初始化
app.py         Flask 后端 API
index.html     Vue3 + ECharts 前端单页
```

## 期末上机 4 项查询

| 查询 | 菜单入口 | 接口 | 说明 |
|------|----------|------|------|
| Q1 | 查询1·区域内设施 | `/api/q1?region=高新区&type=` | 指定区域内设施编号/类型/安装日期/状态 |
| Q2 | 查询2·事件处理情况 | `/api/q2?start=2026-11-01&end=2026-11-12&type=` | 时间范围内事件类型/报告时间/负责部门/处理人员/状态 |
| Q3 | 查询3·维修人员统计 | `/api/q3?start=2026-11-01&end=2026-11-12` | 各维修人员任务数/已完成数/平均处理时长 |
| Q4 | 查询4·区域综合分析 | `/api/q4?start=2026-11-01&end=2026-11-12` | 各区域事件数/完成率/平均时长 + 环境监测变化 |

## 功能模块

- **平台概览**：KPI 指标卡 + 事件趋势/类型图表
- **数据模型**：12 表结构 + ER 关系图
- **基础设施管理**：设施列表/统计/新增/删除
- **事件报告处理**：事件列表/统计/上报/删除
- **资源调度**：任务列表/派单/完成
- **环境监测**：设备清单 + PM2.5/噪音/温湿度趋势
- **4 项期末查询**：带筛选条件 + 结果表格 + 图表
